# Benchmark Results Directory

This directory stores reproducible machine-readable benchmark evaluation files generated by `routone.evaluation.harness`:

- `benchmarks.json`: Complete serialized `BenchmarkReport` containing method names, speaker-attributed WER (SA-WER), standard WER, overlap-specific WER, per-speaker recall, latency percentiles (P50, P90, P95), separation invocation rate (SIR), and Pareto optimality analysis.
- `benchmarks.csv`: Standard comma-separated tabular summary for easy spreadsheet analysis, publication plotting, and CI regression checks.

To regenerate these results deterministically, run:
```bash
make eval
# or
.venv/bin/python -c "from routone.evaluation.harness import BenchmarkHarness; BenchmarkHarness().run_benchmark(save_results=True)"
```
